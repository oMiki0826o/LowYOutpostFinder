# Third-party software in macOS JAR releases

The architecture-specific macOS JARs embed CPython 3.13.16 and Tcl/Tk 9.0 from
the `python-build-standalone` 20261013 release maintained by Astral. The pinned
download URLs and SHA-256 digests are recorded in `runtime-lock.json`.

The complete Python license text is preserved in each JAR at:

`payload/runtime/lib/python3.13/LICENSE.txt`

The project itself remains licensed under the repository `LICENSE` file.
